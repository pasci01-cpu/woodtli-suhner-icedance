# Leonie Woodtli & Timon Suhner – Ice Dance Results

A static website with every competition result of the Swiss ice dance couple from season 2024/25 onward: scores, a score progression chart, personal bests, official ISU videos and Instagram posts.

- Data: `data/results.json`
- The page is generated from `template.html` + `teams.json`: run `python3 build.py` after any edit
- Update procedure: [UPDATE.md](UPDATE.md)
- Hosted with GitHub Pages; no build step needed on the server.
